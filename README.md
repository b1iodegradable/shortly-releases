# Shortly

Приложение для Windows, которое превращает длинное видео в короткие вертикальные клипы для Shorts, Reels и TikTok.

Загрузите подкаст, стрим или серию. Shortly распознает речь, найдёт сильные моменты, кадрирует их по лицу и добавит субтитры. На выходе получаются клипы 9:16, готовые к публикации.

**[Скачать последнюю версию](https://github.com/b1iodegradable/shortly-releases/releases/latest)**: файл `Shortly-Setup-<версия>.exe`

## Для кого

Для авторов, клипмейкеров и всех, кто ведёт каналы с короткими видео и не хочет часами монтировать вручную.

## Что умеет

- **ИИ-нарезка.** Сама находит лучшие моменты. Можно подсказать, что искать: смешное, споры, советы.
- **Стримы с вебкой.** Раскладка «вебка + игра» в одном вертикальном кадре и поиск моментов по реакциям.
- **Нарезка подряд и вручную.** Случайные фрагменты нужной длины или точные куски, отмеченные на таймлайне.
- **Форматы кадра.** Кроп по лицу, размытый фон, Brainrot Bubble, вебка сверху.
- **Субтитры.** Распознаются автоматически, их можно править и выбирать стиль. Вшиваются в видео.
- **Реклама.** Баннер поверх клипа и до пяти видеовставок в клипе. Клип на время вставки встаёт на паузу или идёт дальше тише, а положение каждой вставки можно поменять после нарезки.
- **Уникализация.** Отдельные копии клипов для нескольких каналов.
- **Шаблоны.** Настройки сохраняются под именем, например отдельно для каждого канала.
- **Скачать всё.** Архив клипов, по желанию с описаниями от ИИ.

Тяжёлая обработка видео идёт на вашем компьютере, поэтому ролики никуда не загружаются целиком.

## Требования

- Windows 10 или 11, 64-бит
- Несколько гигабайт свободного места: компоненты и модель распознавания речи
- Интернет: при первом запуске скачиваются компоненты, а при нарезке приложение связывается с сервером
- Видеокарта не обязательна. Видеокарта NVIDIA заметно ускоряет распознавание речи, на AMD и Intel оно пока идёт на процессоре

Python и другие компоненты ставить отдельно не нужно: всё входит в установщик или скачивается при первом запуске.

## Установка

1. Скачайте `Shortly-Setup-<версия>.exe` со [страницы релизов](https://github.com/b1iodegradable/shortly-releases/releases/latest) и запустите его.
2. Первый запуск занимает около 10 минут: приложение скачивает компоненты и модель распознавания речи. Ход видно на экране загрузки. Следующие запуски проходят быстро.
3. Войдите через Telegram: приложение покажет ссылку на бота и код для сверки.

Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Так бывает с программами без платной цифровой подписи.

## Аккаунт и тарифы

Для работы нужен аккаунт. Вход через Telegram-бота, при первом входе начисляются бесплатные минуты на пробу. Дальше нужна подписка: тарифы — в боте и в его кабинете (кнопка «Кабинет» у поля ввода).

Есть промокод? Введите его в кабинете бота или командой `/promo`. Пригласить друга — `/invite`.

## Обновления

Приложение обновляется само: при запуске проверяет новую версию и ставит её. Что изменилось, смотрите на [странице релизов](https://github.com/b1iodegradable/shortly-releases/releases).

## Если что-то не работает

Напишите в поддержку через Telegram-бота. Приложите описание проблемы и, если есть, текст ошибки с экрана загрузки.
