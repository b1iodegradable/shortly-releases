# Shortly

Приложение для компьютера, которое превращает длинное видео в короткие вертикальные клипы для Shorts, Reels и TikTok.

Загрузите подкаст, стрим или серию: Shortly распознает речь, найдёт самые сильные моменты, кадрирует их по лицу и добавит субтитры, обложки и описания. На выходе получаются клипы, готовые к публикации.

## Для кого

Для авторов, клипмейкеров и всех, кто ведёт каналы с короткими видео и не хочет часами монтировать вручную.

## Что умеет

- **ИИ-нарезка:** сама находит лучшие моменты, можно подсказать, что искать
- **Стримы:** раскладка «вебка + игра» и поиск моментов по реакциям
- **Пересказ:** собирает из видео один озвученный ролик
- **Нарезка подряд и ручная нарезка:** случайные фрагменты или точные куски на таймлайне
- **Мидролл:** видеовставка посреди клипа
- **Уникализация:** отдельные копии клипов для нескольких каналов
- **Субтитры:** стили, редактирование и прожиг в видео
